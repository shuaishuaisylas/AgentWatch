图片中的桌面、文档、时间、数字与状态都是人工生成内容，不是本机截图或真实会话。没有复制用户提供的音乐窗口截图、人物图片或歌词到仓库。

- 单行无图标，只常驻执行与待处理计数。

- 真正透出窗口后方内容的原生材质；图只是透明随背景的示意。
- 边缘线长度对应一个固定来源的已用额度，执行高光只在线内流动。

图中的发光、字体、透明程度和位置均需在实际桌面中验证。图片不承担接口、精确像素、动态材质或焦点行为的实现证明。
