# 前后端协作交接

AgentWatch 是在使用者自己的 Mac 上运行的本机看板。仓库提供应用代码；真实会话、用量和账号信息留在每位使用者本机。合作者不需要访问项目维护者的账号或会话。

## 第一次启动

准备 Python 3.9 及以上，在终端检查 `python3 --version`。前端无需 npm；如需运行 JavaScript 语法检查，再准备 Node.js。

```sh
git clone https://github.com/shuaishuaisylas/AgentWatch.git
cd AgentWatch
python3 -m agentwatch --demo --port 8767 --open
```

浏览器访问 `http://127.0.0.1:8767`。页面由 Python 后端提供，接口、cookie 与 CSRF 均在同一来源。保留服务终端；按 `Control + C` 停止。端口占用时换一个未占用端口。

演示数据全部人工生成，时间随样例刷新移动并保留相对陈旧程度。它只用于开发和界面验收，不能证明真实客户端接入成功。演示不运行采集或进程探测，来源和数据库使用临时目录；退出后清理，修改的会话别名不会保存到下一次运行。后端拒绝演示中的应用跳转及 Claude 接入配置操作。

没有真实会话也可以开发总览、统计和设置页面及常见状态；其他边界场景按需补人工样例。需要检查真实采集时，在仓库根目录使用 `python3 -m agentwatch --open`，这会读取运行者自己的记录。不要为前端开发共享真实记录或开启 Claude 状态增强。

## 分工和目录

| 位置 | 职责 | 协作方式 |
| --- | --- | --- |
| `web/index.html` | 页面结构、无障碍语义 | 前端主要修改 |
| `web/app.js` | 数据请求、筛选、卡片/图表/弹窗 | 前端主要修改 |
| `web/style.css`、`web/favicon.svg` | 视觉、响应式与图标 | 前端主要修改 |
| `agentwatch/collector.py`、`store.py` | 数据来源、解析、状态、统计 | 后端主要修改 |
| `agentwatch/server.py`、`navigation.py`、`configuration.py` | 本地 API、安全边界、跳转和配置 | 后端主要修改 |
| `tests/` | 数据和接口回归 | 随相应行为变更维护 |
| `docs/API.md` | 双方共同的字段与行为约定 | 变更接口时同步 |

保持原生前端即可运行。静态文件按请求读取，修改后刷新页面；Python 代码修改后重启后端。不要直接打开 `web/index.html`，也不要另起 Vite/Live Server 后通过关闭 CORS 或 CSRF 来联调。

## 接口变更如何配合

先在需求或 PR 中写出字段名称、类型、可空性、单位和影响的页面，再实施最小变更。优先增加兼容字段；删除字段、改变状态枚举或改写统计含义时，前后端与测试必须在同一批改动中完成。人工演示数据也要覆盖新行为。

`docs/API.md` 是联调约定，最终行为以相应代码和测试为证据。接口更新时同步文档，并在 PR 说明旧页面如何兼容；不要让前端自行猜测缺失数据。

## 提交前验收

- 从仓库根目录能按文档启动演示，不依赖个人绝对路径、账号或会话。
- 演示标记清晰；演示中应用跳转和 Claude 配置操作不可执行；别名只写临时数据。
- 工具、项目、主子关系和状态筛选正确；空态不会显示成连接失败。
- 未知 token 显示“—”；缺少上下文分母不画占用百分比；陈旧等待保留提示。
- 日、周、月、年及前后日期可切换，图表和工具统计跟随相同范围。
- 详情、别名和接入设置可用；宽屏与窄屏没有遮挡或不可点击的控件。
- 相关自动检查通过，并说明浏览器实测范围；未进行的真实客户端验证明确保留。
- 提交内容没有真实记录、数据库、账号设置、备份、凭据或个人截图。

建议在新分支完成小范围改动，PR 说明问题、最终行为和验证证据。不要把未提交的他人改动一并提交，也不要在共享分支直接覆盖历史。

## 已知边界

实时列表会排除 Codex 已归档会话、归档父会话的后代及内部审核 Agent；正常子 Agent 继续展示。共享进程在线不能覆盖隐藏规则。归档与恢复会在重新发现来源后生效；历史用量和别名保留，历史项目仍可筛选。已有本地数据库会自动补充可见性字段，无需清空重采；具体优先级见 API 文档。

Claude 真实 hooks 尚未完成所有客户端入口的端到端验收；WorkBuddy 精准等待状态与上下文占用尚未接入；豆包工作、Claude Cowork 和普通 Chat 尚未接入；桌面顶部灵动岛仍未实现。应用跳转按来源精度执行，打开应用不等于已定位原会话。

订阅卡片由独立 `GET /api/subscriptions` 提供，不受会话筛选影响。Codex 读取本地额度快照；Claude 需要状态栏实际报告；WorkBuddy 积分 API 已实现，但需要正式 OAuth 访问凭证，当前账号尚未验证。前端不得把“接口实现”显示为“当前账号已授权”，也不得把旧快照或已过重置时间的值标为实时剩余。详见 API 文档与 README 的配置说明。
