# 无痛胶囊

macOS 原生单行挂件。保持可见以便调试，确认执行或待处理中大于零的项单独呈现（例如 `1 执行 · 2 待处理`、`1 执行` 或 `2 待处理`）。两项都没有时文字为空，胶囊和额度边缘仍显示，可点击检查详情；连接中、待确认、读取失败及过期状态不生成常驻文字。仅菜单“暂隐胶囊”会隐藏面板。人工数据有内容时会加 `演示 ·`。真实背景通过系统 `NSVisualEffectView` 的 `behindWindow` 材质混合，圆角遮罩只降低材质覆盖度，不降低文字和额度线的不透明度。

## 运行

需要 macOS、Python 3.9+ 和带 Swift 5.9+ 的 Command Line Tools / Xcode，无 npm 依赖，无需安装第三方 Swift 包。产品部署目标 macOS 13；本轮实际验证为 arm64、macOS 27.0.1、Swift 6.4，其他系统/显示器尚须实机验证。

在仓库根目录：

```sh
# 完整人工演示：创建自己的临时服务，自动选空闲端口
./desktop/scripts/run-demo.sh

# 真实模式：先使用原来的“启动看板.command”运行本机服务
./启动胶囊.command

# 如本机服务使用其他端口
./启动胶囊.command --url http://127.0.0.1:8768
```

真实启动器只连接既有服务，退出胶囊不会关闭该服务。演示启动器不复用占用端口的进程，只停止自己创建的演示服务与胶囊；可传 `--port 8767` 指定演示端口，冲突会失败。演示不读取真实 Agent、修改配置或打开真实 Agent。

仅构建：

```sh
./desktop/scripts/build.sh
```

产物为 `desktop/.build/无痛胶囊.app`，可直接打开，默认连接 `http://127.0.0.1:8766`。这是本机构建、临时签名的应用，尚未做分发签名、公证、安装器或通用架构打包。构建目录已忽略，不提交二进制。已有胶囊运行时，请先在菜单栏退出再切换服务；不在同一进程内切换来源，避免旧响应串入另一环境。

构建脚本发现胶囊仍在运行，或无法确认运行状态时会直接停止，不覆盖现有应用。测试用的演示胶囊也需先退出。

## 操作

- 鼠标经过不展开，点击才显示轻详情；面板不成为 key/main 窗口。点击外部直接作用于原应用，并收起详情。
- 以真实圆角轮廓判断鼠标命中，透明空角穿透到后方应用；事件监测与低频检查只切换鼠标穿透状态，拖动按住期间不切换。
- 超过 4pt 才算拖动，松手不触发展开；靠近可用屏幕边缘 16pt 内吸附，留 8pt 间隙。记录相对位置，显示器变化时夹回可见区域。
- 菜单栏文字“胶囊”提供显示、暂隐、重置位置、额度来源、完整看板、刷新和退出。主动暂隐不会因新事件自动恢复。没有系统通知、声音、全局快捷键或开机自启。
- 执行数只统计确认执行的主会话，不把子 Agent 加入。待处理数是“需要你回复/批准”与“本轮结束、尚待查看”的主会话并集；明确子树内的人工请求归到根主会话，同一根有多项也只计 1。同一主会话可同时执行与待处理。自动批准和单纯异常不计入待处理。
- 两个数字来自服务端截断前的独立聚合，不从最多 160 张卡片推算。缺少新版人工交互字段或缺可靠人审证据时，数据和详情保留未知；常驻层不显示待确认，也不将未知补成 0 或把旧 waiting/error 相加当成人工待处理。
- 轻详情标题仅显示“待回复 / 待批准、正在执行、完成待查看”，不附带右键操作提示文字；每条保留名称、平台、状态、相对时间。人工请求按实际处理信号移除，也可在用户核对原客户端后显式消除本地提醒；完成卡可右键标为已看过。同一会话只出现一次，人工待处理优先；执行与待回复标签可并存。完成待查看仅使用明确的本轮结束事件，近 24 小时最多 5 条；已读移出后补下一条，不把普通空闲或进程退出当完成，也不代表业务目标验收成功。
- 名称优先显示客户端已保存的项目名。Codex 的工作目录不再冒充侧栏项目：无正式项目名时先显示会话名（人工别名 → 侧栏标题），再以可读目录兜底；其他平台保留原项目名优先。内部项目 ID 不用于兜底，均无名称时显示“未命名会话”。名称完整显示，较长时随面板宽度自然换行、行高自动增加，不另设字符显示上限，不提供鼠标悬停功能。Codex 会话名优先只读 `session_index.jsonl` 的 `thread_name`，与旧线程 SQLite 的 `title` 区分；项目名只读客户端项目元数据，不从对话正文生成。滚动条平时隐藏，仅滚动或拖动期间显示，停止后自动隐藏，不改变系统滚动条偏好。
- 点击整张会话卡片调用既有跳转，没有独立跳转按钮。可定位会话时定位会话；只能打开应用、项目或原终端标签页时明确标注，不承诺所有来源都能精确定位。演示卡片禁用跳转。
- 对“完成待查看”，右键一次即确认该次完成已读，成功后立即移除并减数，无二次按钮。左键精确会话跳转成功仍保留自动已读；失败或仅打开应用/项目/原终端标签页不自动销账。人工待回复/待批准不会因完成已读而清除。
- 对“待回复 / 待批准”，右键一次即消除当前批次的本地提醒，成功后立即移除并更新数字，无二次按钮；普通左键跳转和查看保持提醒。这不替你回答或批准，也不把来源中的请求改成已解决。版本来自完整明确根子树，批次变化时要求重新读取；后续新请求仍提醒，旧回放不会复活已消除的提醒，执行与未知覆盖保留。没有可靠批次版本或正在处理请求时右键不执行。
- 当前接入无法可靠判断你在原客户端单纯查看了某条结果，不使用应用前台、窗口焦点或文件更新时间猜测已读。实际回答/批准仍由独立状态链路同步。已读按完成版本持久保存，同一会话再次完成会重新出现；旧卡的迟到确认不会清掉新结果。首次启用仅展示近 24 小时的已知未读完成，不回溯更久。
- 额度来源移到菜单栏“胶囊 → 额度来源”，身份为平台、bucket、key。首次仅在取得有效 Codex 周窗口时默认选它；之后不随执行平台变化。取消绑定也是持久选择。
- Cursor 官网读数是独立的页面快照，额度菜单按池与周期选择；提示明确显示“页面快照”和约数。页面读取时间不冒充官方更新时间，过期或进入可能重置日期后保持未知，不自动补满。获取与手动导入规则见 [API](../docs/API.md)；后台轮询不会自动登录或重新读取官网。
- 边缘线按真实完整路径比例画出已用额度，从顶部中点顺时针延伸。随胶囊保持显示，无任务时也保留；已用 0% 不补亮段，100% 闭环表示额度用尽。未知为中性虚线，旧值弱化虚点，重置后等待新报告。
- 仅有新鲜状态、确认执行、有效非零额度、可见且允许动态时，微光才在已用段内部以 5 秒一轮流动。系统减少动态效果、休眠、暂隐、断线与过期均停止微光。降低透明度/增强对比度时采用系统材质回退。
- 原应用跳转仅发送用户点选的会话 ID 给现有 `/api/jump`，遵从服务返回的可用性、文字和精度。挂件不替用户回复或批准。

## 数据与安全

每个完整 `http://127.0.0.1:端口` 使用独立临时 URLSession 和内存 cookie/CSRF；不访问系统共享 cookie 或凭据。先取得本项目首页，再调用 API。所有重定向被拒绝，POST 保持 CSRF 校验且不自动重试，GET 401 最多重新认证并重试一次。后端兼容增加人工交互、未读完成元数据、`POST /api/inbox/read` 与 `POST /api/attention/dismiss`，复用原认证校验。显式消除本地提醒或确认已读成功后，客户端丢弃先前在途的旧快照并重新读取；未改变客户端信任或批准策略。

状态和额度各 4 秒读取，暂隐时各 12 秒；同端点只有一个在途请求。请求超时 6 秒，状态距最后成功读取 15 秒后失去新鲜性并清空旧计数文字，胶囊保持可见，详情提示状态待更新；读取失败或休眠时也不继续显示旧执行／待处理数量。额度来源时间、重置时间和平台/窗口状态另行判断，读取成功时间不能替代来源时间。失败保留内存中的旧快照，不补零；新鲜状态恢复前不展示旧数量。

偏好仅包含位置、暂隐及额度身份，真实/演示/材质验证使用不同偏好域。原生客户端会话只在内存中展示；不记录 cookie、CSRF、对话、工具正文或截图。后端另存最少交互身份、问题索引和时间，以支持重启后保留未答请求；独立保存本地提醒消除的最少身份及时间，不改原请求的已解决时间。不保存问题、答案或工具参数。`NSAllowsLocalNetworking` 仅允许本地网络访问，没有全局任意网络例外。

## 检查与复验

```sh
./desktop/scripts/test.sh
./desktop/scripts/test-transport.sh
./desktop/scripts/test-controller-read.sh
# 连接自己新启动的演示服务；会 rescan 并消除一批人工本地提醒
./desktop/scripts/test-demo-api.sh http://127.0.0.1:演示端口
# 先退出运行中的胶囊；只显示人工窗口，不连接 API
./desktop/scripts/test-lifecycle.sh --run
python3 -m unittest discover -s tests -v
node --check web/app.js
git diff --check
```

`test.sh` 自动定位 CLT / Xcode 的 Swift Testing 框架；测试工具本身可能需要 macOS 14+，产品不依赖 Testing。构建脚本使用 SwiftPM 当前可用的 native 构建器，避免本机默认 swiftbuild 在受限环境生成 dSYM 的失败；Swift 6.4 会显示此构建器的弃用提示。`--disable-sandbox` 仅用于无外部依赖的本地 SwiftPM 编译子进程，不改变 HTTP、系统或 Agent 安全策略。

原生材质单独复验，不连接 API：

```sh
./desktop/scripts/run-focus-host.sh       # 在一个终端启动人工文档
./desktop/scripts/run-material-probe.sh   # 在另一终端启动人工胶囊
```

材质验证模式可把最少的自身窗口/焦点状态写到 `/tmp/agentwatch-material-probe.json`；不含会话身份、正文或凭据。完整客户端也可在测试启动时设置 `AGENTWATCH_CAPSULE_QA=1`，只用于开发验收。材质版退出后重新正常构建，清除产物中的验证标记。

`AGENTWATCH_CAPSULE_QA_DETAILS=1` 是人工详情布局检查模式：启动时隐藏胶囊、展开详情，并暂停外部点击收起。它不用于普通运行或焦点/穿透验收。`test-lifecycle.sh` 使用人工 probe、真实 AppKit 窗口及模拟系统通知，不会令机器实际休眠；默认不带参数只编译 runner。

自动测试、人工桌面验收、真实客户端 hooks/跳转的证据分别记录在 [验收记录](ACCEPTANCE.md)。编译成功不等于所有桌面行为已经验收。
